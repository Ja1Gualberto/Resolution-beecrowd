# 🐝 Resoluções Beecrowd (URI Online Judge)

![Linguagens](https://img.shields.io/github/languages/top/Ja1Gualberto/Resolution-beecrowd?style=flat-square)
![Status](https://img.shields.io/badge/Status-Em%20Progresso-green?style=flat-square)

Repositório dedicado ao armazenamento das minhas soluções para os desafios da plataforma [Beecrowd](https://www.beecrowd.com.br/). O objetivo é exercitar a lógica de programação, algoritmos e estruturas de dados.

---

## 🚀 Tecnologias Utilizadas

As soluções foram implementadas utilizando as seguintes linguagens:

* **Python**
* **C / C++**

---

## 📂 Estrutura do Repositório

O projeto está organizado por linguagem de programação:

| Pasta | Linguagem |
| :--- | :--- |
| `c/` | C |
| `python/` | Python |
| `c++/` | C++ |

> **Dica:** Cada arquivo de código é nomeado com o ID do problema (ex: `1001.py`) para facilitar a busca.

## 🛠️ Como executar os códigos

1.  Clone o repositório:
    ```bash
    git clone [https://github.com/Ja1Gualberto/Resolution-beecrowd.git](https://github.com/Ja1Gualberto/Resolution-beecrowd.git)
    ```
2.  Navegue até a pasta da linguagem (`python/`, `c/` ou `c++/`) e execute conforme a linguagem:
    * **Python:** `python3 1001.py < input.txt`
    * **C:** `gcc 1001.c -o 1001 && ./1001`
    * **C++:** `g++ 1001.cpp -o 1001 && ./1001`
